# Methodox Technologies, Inc.

Welcome!

Methodox Technologies, Inc. is a Toronto-based independent software studio. Our flagship project is **Divooka**, a general-purpose visual programming system: programs are graphs of nodes that you can run, inspect and debug, with ready-to-use tools for data, images, audio, procedural worlds, applications and more. This GitHub organization is where we share parts of our work with the community.

## Divooka

* [**Divooka Explore**](https://store.steampowered.com/app/4422920/Divooka_Explore/) is the learning and exploring edition, with a free [demo](https://store.steampowered.com/app/4770820/Divooka_Explore_Demo/) on Steam.
* [**Divooka Compute**](https://store.steampowered.com/app/3381720/Divooka_Compute/) is the professional edition, planned for release in December 2026.
* The [Methodox Wiki](https://wiki.methodox.io/) is the manual. The [Divooka website](https://divooka.com/) has the overview and a browser-based taster.

## What is here

Public repositories include the [Mandelbrot and ray tracer benchmarks](https://github.com/MethodoxTech/DivookaBenchmark_Mandelbrot) we use to measure Divooka against other languages, and small tools and libraries we build and maintain along the way, such as EasyShell and several managed (pure C#) ports. Divooka itself is not open source at the moment.
